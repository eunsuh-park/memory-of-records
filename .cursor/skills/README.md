# 프로젝트 워크플로 스킬

디자이너가 요청을 쌓고 → 정리하고 → 합의한 것만 로드맵으로 실행하며 → 일지를 남기는 흐름이다.

| 스킬 | 폴더 | 하는 일 |
|------|------|---------|
| 1 | `backlog-capture` | 시킨 일을 `Backlog.md` Inbox에 누적 |
| 2 | `backlog-enrich` | 전체 점검 · 유사 그룹핑 · **내용 구체화**(삭제·간소화 금지) |
| 3 | `backlog-to-roadmap` | 우선순위 제안 → 확인분만 `Roadmap.md` → **한 항목씩** 구현·날짜 기록 |
| 4 | `project-journal` | 프롬프트/히스토리 기반 일지 → `docs/journal/YYMMDD_작업명.md` |
| 5 | `conventional-commits` | git 커밋 메시지를 Conventional Commits 1.0.0 + 한국어 「~한다」로 작성 |

관련 산출물:

- `Backlog.md` (루트)
- `Roadmap.md` (루트)
- `docs/journal/`
