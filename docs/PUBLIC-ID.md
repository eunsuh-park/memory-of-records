# Public ID 규칙

Notion 노트북 `public_id` 정책. 앱 코드는 이 값을 생성하지 않는다. DB에 직접 넣는다.

형식: `{PREFIX}-{YEAR}-{SEQ}`  
예: `DIRY-2024-0001`

---

## 일련번호 (SEQ)

- 네 자리, 0으로 채움: `0001`, `0002`, …
- **각 PREFIX + YEAR 그룹의 첫 노트는 항상 `0001`**
- 같은 그룹에 노트가 하나뿐이면 `0001`만 쓴다 (`0000`은 쓰지 않음)
- 같은 그룹 안 정렬: 시작일 내림차순 → 같으면 이름 오름차순
- 새 노트를 같은 그룹에 추가하면 기존 최댓값 + 1

---

## 접두사 (PREFIX)

| PREFIX | 유형 |
|--------|------|
| DIRY | 다이어리(일기장) |
| PLNR | 스케줄러 |
| MEMO | 수첩/메모지 |
| SKTC | 스케치북 |
| STDY | 줄공책 · 학습/독서 (학습노트, 독서록, 독후감, 받아쓰기, JLPT, 구글PM 등) |
| WORK | 줄공책 · 업무일지 |
| NOTE | 줄공책 · 그 외 |

---

## 연도 (YEAR)

기간은 `period_start` ~ `period_end` 기준.

1. **시작·종료 둘 다 없음** → `9999`
2. **종료일 없음** (아직 쓰는 중) → 시작연도
3. **사용 기간 2년 이상** (포함 일수 730일+) → 시작연도
4. **두 해에 겹친 일수가 같음** → 시작연도
5. **그 외 (2년 미만)** → 겹친 일수가 가장 많은 연도

### 예시

| 노트 | 기간 | 선택 | 이유 |
|------|------|------|------|
| 2022-2024_기타(위클리) | 2022-01-01 ~ 2024-12-31 | **2022** | 2년 이상 → 시작연도 (윤년 2024가 아님) |
| 2022-2023_일기장 | 2022-01-01 ~ 2023-12-31 | **2022** | 일수 동점 → 시작연도 (최신 2023이 아님) |
| 2025-2026_해빗트래커 | 2025-12-01 ~ 2026-03-11 | **2026** | 2년 미만, 2026이 더 김 |
| 03_연도미상_연습장_노란색 | 없음 | **9999** | 시작·종료 둘 다 미상 |
| (새 노트, 종료일 비움) | 2026-03-01 ~ | **2026** | 아직 쓰는 중 |

날짜가 뒤집혀 있으면(종료 < 시작) 시작연도를 쓴다.
